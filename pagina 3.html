Hardware de una Computadora


El hardware son las partes físicas de una computadora, como el teclado, monitor, memoria RAM y disco duro.

Tipos de Hardware

  • Procesador (CPU)
  • Memoria RAM
  • Disco duro o SSD
  • Tarjeta madre
  • Fuente de poder

¿Cómo actualizar el hardware?

  1. Apagar la computadora.
  2. Desconectar todos los cables.
  3. Abrir la tapa del gabinete.
  4. Instalar la nueva pieza de hardware.
  5. Encender la computadora y probar.
